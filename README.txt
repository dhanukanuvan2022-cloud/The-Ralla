THE RALLA — WEBSITE PACKAGE

Files:
- index.html: main website
- assets/style.css: responsive styling
- assets/app.js: menu filters, cart and WhatsApp order builder
- assets/images/: photographs extracted from the supplied PDF and upscaled to a 4K long edge

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Firefox/Chrome. Internet is needed for Google Maps embed and Google Fonts.

HOW TO UPDATE
- Phone / WhatsApp number is currently set to +94 76 353 5399 in index.html and assets/app.js. Change 94763535399 in the WhatsApp links if the restaurant confirms another number.
- Current menu prices were not verifiable online, so the site clearly asks customers to confirm current prices rather than inventing prices. Edit the dishes array in assets/app.js when the official menu and prices are confirmed.
- Google Maps uses a search query for The Ralla, Negombo, plus the available Plus Code 6RPR+Q8V. Check the pin before publishing.
- Google reviews button opens the Google Maps listing; no fake review quotes are shown.

PHOTO QUALITY
The PDF photos were extracted from the supplied document and enlarged with high-quality resampling plus mild colour/sharpness enhancement. Upscaling increases pixel dimensions but cannot restore detail absent from the originals.

This is a static HTML/CSS/JavaScript site; it does not need a backend to send the prepared order to WhatsApp. WhatsApp must be installed or available in the browser, and the restaurant must confirm each order.
